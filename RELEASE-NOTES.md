# Galathil

- Create and incrementally update one shared Galathil Output mod with ESPFE plugin(s) and a combined SkyPatcher NPC config.
- Link the output to each source asset mod with readable text notes, named by source ESP; the output also has a list of every linked asset mod.
- Disable a source ESP in the selected MO2 profile when the output and other active plugins no longer need it. Keep its asset mod enabled and its ESP file available for Galathil to inspect or restore.
- Leave source ESPs enabled when another plugin or output master requires them, and report the reason.
- Ask before SkyPatcher changes race or sex; support Skyrim SE 1.6.1130+ extended ESL local IDs.
- Keep the previous output and legacy generated configs recoverable in a backup.

Tested only on Skyrim SE 1.6.1170. Requires Windows x64, Mod Organizer 2, the .NET 10 Desktop Runtime, and SkyPatcher for shared output.
